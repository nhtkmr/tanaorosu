# 設備予備品・図面 階層ビューア（Excel）

工場マップ → 設備写真 → 詳細写真 → 組図 → 部品図面／購入部品 を、
**画像の上のポインターをクリックして辿れる** Excel ツールです。購入部品・部品図面は棚番で検索できます。

- 本体： `予備品図面管理.xlsm`
- 表示用画像（JPG/PNG）： `img\`
- 原本ファイル（PDF など）： `pdf\`

ブック・`img`・`pdf` は **フォルダごと** コピー／移動してください（相対パスで記録しているため、フォルダごと動かせば壊れません）。

---

## 1. 最初に（マクロを有効にする）

このツールは VBA マクロで動きます。共有フォルダに置くとマクロが無効化されることがあるので、
置き場所を「信頼できる場所」に登録してください。

1. Excel を開く → **ファイル > オプション > トラスト センター > トラスト センターの設定**
2. **信頼できる場所** → 「ネットワーク上にある信頼できる場所を許可する」にチェック
3. **新しい場所の追加** → このフォルダを指定 → 「この場所のサブフォルダーも信頼する」にチェック

登録しない場合は、ブックを開いたときに出る黄色いバーの **［コンテンツの有効化］** を毎回押してください。

---

## 2. 画面（［ビュー］シート）

| ボタン | 動き |
|---|---|
| ← 戻る | 1 つ前に見ていた項目に戻る |
| ホーム | 工場マップ（設定の「ホーム」）に戻る |
| 原本を開く | 登録された PDF などを、いつものビューアで開く |
| 棚番検索 | ［部品一覧］シートへ移動 |
| 編集モード：ON/OFF | ポインターを動かせる状態に切り替える |
| ポインター追加 | 位置未設定の子に、ポインターを 1 つ置く |
| 位置を保存 | 動かしたポインターの位置を記録する |
| 子として新規登録 | ［登録］シートへ移動（今見ている項目が親になる） |
| 既存を子に追加 | **登録済みの項目**を、今見ている項目の子にする（複数の図面で共用する部品など） |

- 画像の上の四角・丸が **ポインター**。クリックすると子（設備・組図・部品など）へ移動します。
- 右側に、今見ている項目の情報（**棚番**・型式・在庫・購入先など）と、**子の一覧**が出ます。
  子の一覧は行をクリックしても移動できます（ポインターを置いていない子もここから辿れます）。
- 「使用先（親）」は、その部品がどの図面で使われているかの逆引きです。
  **青字のところをクリックすると親へ戻れます**（複数あるときは番号で選びます）。

---

## 3. 登録のしかた

### 3-1. 子を追加する（いちばんよく使う手順）

1. ［ビュー］で **親になる項目**（工場マップ、設備、組図など）を表示しておく
2. ［子として新規登録］→ ［登録］シートが開く
3. **種別** と **名称** を入力（購入部品・部品図面なら **棚番** や型式・在庫も）
4. ［画像を選ぶ...］で表示用 JPG を、［原本を選ぶ...］で PDF を指定
   （選んだファイルは自動的に `img\` `pdf\` にコピーされ、相対パスで記録されます）
5. ［表示中の項目の子として登録］を押す
   → 親の画像の中央にポインターが置かれ、**編集モード**になります
6. ポインターを **ドラッグ**して現物の位置に合わせ、大きさも調整
7. ［位置を保存］を押す

### 3-2. 種別の使い分け

| 種別 | 使うもの | ID の頭 |
|---|---|---|
| マップ | 工場レイアウト図 | MAP- |
| 設備 | 設備の全景写真 | EQ- |
| 詳細 | 設備の部位（アップ写真） | DT- |
| 組図 | 組立図・アッセンブリ図 | AS- |
| 部品図面 | 自社製作品の部品図 | DW- |
| 購入部品 | 買って在庫する部品 | PT- |

**購入部品・部品図面** にしたものだけが［部品一覧］（棚番検索）に出ます。

### 3-3. 同じ組図・部品を複数の親で使う

同じベアリングが 2 つの組図で使われている、同じ組図が 2 台の設備に付いている——こうした場合は
**項目（ノード）を 1 つだけ作り、親ごとに参照を足します**。同じものを二重に登録しないでください。

1. ［ビュー］で **もう一方の親**（別の組図・別の設備）を表示する
2. ［既存を子に追加］を押す
3. 名称・ノードID・型式・棚番 の一部を入力（例: `ベアリング`）→ 候補を番号で選ぶ
4. ポインターが中央に置かれ編集モードになるので、位置を合わせて［位置を保存］

| 何が | どこに付くか |
|---|---|
| 棚番・在庫・型式・メーカー・購入先・画像・原本 | **項目（ノード）に 1 つ**。どの親から見ても同じ。1 か所直せば全部直る |
| ポインターの位置・バルーン番号・数量 | **親ごと**。組図Aでは①、組図Bでは⑤、数量も別々にできる |

- その項目を開くと「使用先（親）」に全ての親が並びます。クリックで行き来できます。
- ［部品一覧］の「使用先」列にも全ての親が出るので、「この部品を使っている図面」を一覧で確認できます。
- 既にその親の子になっている項目は候補に出ません（二重登録の防止）。
- 親子をやめたいときは、［リンク］シートの該当行を削除します。

### 3-4. PDF が原本のとき

Excel はシート上に PDF を描けないので、**表示用の JPG** と **原本の PDF** を分けて登録します。

- 表示用画像（JPG）… ポインターを載せる絵。PDF ビューアの「画像として保存」、
  図面ソフトの画像書き出し、または PDF を開いて画面キャプチャで作れます。
- 原本ファイル（PDF）… ［原本を開く］で開く、印刷・拡大用の正本。

---

## 4. ポインターの編集

- ［編集モード］を ON にすると、ポインターをクリックしても移動せず、**ドラッグ・サイズ変更**できます。
- 不要なポインターは選んで **Delete**。→ 保存すると「位置未設定」に戻ります
  （**親子の関係そのものは残る**ので、子の一覧からは今までどおり辿れます）。
- 関係ごと消したいときは、［リンク］シートでその行を削除してください。
- 終わったら ［位置を保存］（または ［編集モード］をもう一度押す）。

---

## 5. 棚番で探す（［部品一覧］シート）

- 上の検索欄に **棚番・品名・型式・メーカー・購入先** の一部を入れて Enter（または［検索］）。
- 行の右端 **［▶ 表示］** をクリックすると、その部品の画面に飛びます。
- この一覧は［ノード］シートから自動生成される**表示専用**です。
  内容を直すときは［ノード］シート（または［登録］シート）で直してください。

---

## 6. シートの中身

| シート | 役割 |
|---|---|
| ビュー | 閲覧画面。画像とポインター、情報、子の一覧 |
| ノード | 全対象の台帳。1 行 = 1 つの対象。棚番・在庫・パスもここ |
| リンク | 親子関係とポインター座標。X/Y/W/H は画像に対する 0〜1 の割合 |
| 部品一覧 | 購入部品・部品図面の抽出（棚番検索用・表示専用） |
| 登録 | 新規登録フォーム |
| 設定 | フォルダ名、ホーム、ポインター既定サイズなど |

- 同じ部品を複数の組図にぶら下げられます（［既存を子に追加］＝［リンク］に行が 1 つ増えるだけ）。
  ［ノード］に親の列を持たせていないので、親はいくつあっても構いません。
- 画像とポインターは**保存時にいったん消して**います。ブックが重くならないようにするためで、
  開き直すと自動的に描き直されます。

---

## 7. 配布・共有のしかた

### A. 共有フォルダに 1 つ置く（社内で使うならこれ）

台帳が 1 つで済み、誰かが登録した内容がそのまま全員に見えます。

1. サーバーの共有フォルダに、**このフォルダごと**（`予備品図面管理.xlsm` + `img` + `pdf`）コピーする
2. 使う人は各自の PC で **一度だけ** 「信頼できる場所」にそのフォルダを登録する（→ 1. 最初に）
3. あとはショートカットを配れば終わりです

**複数人で同時に開いたとき**

| | できること |
|---|---|
| 先に開いた人 | 全部（閲覧・登録・ポインター編集・保存） |
| あとから開いた人（読み取り専用） | **閲覧・移動・棚番検索はすべて可**。登録とポインター位置の保存だけ不可 |

- 読み取り専用のときは画面右上に **「読み取り専用（閲覧のみ）」** と出ます。閉じるときに保存を聞かれることもありません。
- 登録する人を決めておき、**作業が終わったらブックを閉じる**運用にしてください（開きっぱなしだと他の人が登録できません）。
- OneDrive / SharePoint の同期フォルダは競合コピーができやすいので、**通常のファイルサーバー**をおすすめします。

### B. 別の工場・別の PC に配る

`tools\New-Package.ps1` で配布用 ZIP を作ります。

```powershell
powershell -ExecutionPolicy Bypass -File tools\New-Package.ps1
# サンプル画像・サンプル PDF を入れずに配るなら
powershell -ExecutionPolicy Bypass -File tools\New-Package.ps1 -NoSample
```

`dist\予備品図面管理_日付.zip` ができます。中身はブック・`img`・`pdf`・`README.pdf`・
`はじめにお読みください.txt` だけで、`src` `tools` `backup` は入りません。

**受け取った側の手順**（`はじめにお読みください.txt` に同じ内容が入っています）

1. ZIP を展開し、フォルダごと置きたい場所へ移す
2. `予備品図面管理.xlsm` を右クリック → プロパティ →
   「セキュリティ: このファイルは他のコンピューターから…」があれば **［許可する］にチェック**
   （メールや ZIP で受け取ると付きます。外さないとマクロが動きません）
3. そのフォルダを「信頼できる場所」に登録する

※ この方法だと台帳は配布先ごとに別々になります。1 つにまとめたいなら A を使ってください。

## 8. 困ったとき

| 症状 | 対処 |
|---|---|
| 画像が出ず「画像ファイルが見つかりません」 | `img\` にファイルがあるか、［ノード］シートのパスが合っているか確認 |
| ボタンを押しても何も起きない | マクロが無効。上の「1. 最初に」を実施 |
| ポインターがずれた | ［編集モード］→ドラッグ→［位置を保存］ |
| ポインターが出ない | ［リンク］シートの X/Y/W/H が空欄。［ポインター追加］で置く |
| 別の共有フォルダに移した | ブック・`img`・`pdf` を**まとめて**移動すれば OK |

## 9. 開発メモ（作り直すとき）

VBA のソースは `src\` にあります。ブックはそこから組み立てています。
**ゼロから作る手順・直し方・ハマりどころは `BUILD.md`（`BUILD.pdf`）にまとめてあります。**

| コマンド | 何をするか | 台帳データ |
|---|---|---|
| `tools\Update-Workbook.ps1` | **通常はこちら。** 入力済みの台帳を読み出す → ブックを作り直す → 書き戻す | **残る** |
| `tools\Build-Workbook.ps1` | ブックをまっさらに作り直す（初回用） | **サンプルに戻る** |
| `tools\New-SampleImages.ps1` | 動作確認用のサンプル画像・PDF を作る | － |
| `tools\Convert-MdToPdf.ps1` | この README を PDF / HTML にする | － |
| `tools\New-Package.ps1` | 配布用 ZIP を dist\ に作る | － |

```powershell
powershell -ExecutionPolicy Bypass -File tools\Update-Workbook.ps1
```

- どちらも実行前に **`backup\予備品図面管理_日付時刻.xlsm`** に控えを取ります。おかしくなったら戻せます。
- 実行には Excel の **「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」** が必要です
  （ファイル > オプション > トラスト センター > トラスト センターの設定 > マクロの設定）。
- 引き継がれるのは ［ノード］［リンク］の全行と［設定］の運用値だけです。
  シートに手で足した列や書式は引き継がれません。`img\` `pdf\` のファイルは触りません。
- ブックを Excel で開いたままだと更新できません。閉じてから実行してください。
